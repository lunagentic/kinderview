# PO 보드 — 1단계 승인 시안 (체크포인트)

- `preview-template.html`: 승인된 UI 템플릿(HTML+CSS+JS, 데이터 없음). `/*DATA*/null` 자리에 데이터를 넣어 미리보기를 만든다.
- `build-preview.py`: 실제 데이터 스냅샷(`poreal.json`, 저장소에 넣지 않음)을 읽어 `po-board-preview.html` 을 만든다.
- 승인 내용: 머리 · 지표 4칸(도넛 · 이번 주 완료 · 진행 중/지연 · 주간 타임라인) · 구성원 칩 · 카드 격자 · 하단 상세(과업 요약 · 하위 업무 · 연계 업무).
- 우선순위: ★ 핵심과업 표시 업무가 1순위로 맨 위, 그 다음 구성원마다 완료 아닌 책임 업무 중 지연 우선·마감 가까운 1건.
- 하위 업무는 간단한 리스트, 진행률은 상세 머리에 한 번만. 댓글·파일·활동 기록 없음.
