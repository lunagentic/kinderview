# 06. 화면 정의

## 6.1 공통 레이아웃

```
┌──────────────────────────────────────────────────────────┐
│ KinderFlow   Overview  Tasks  Issues  Weekly    (img) 김OO│
├──────────────────────────────────────────────────────────┤
│                                                          │
│                      (화면 본문)                          │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

- 진입 기본 화면: **Overview**
- 우상단 프로필 클릭 → `내 담당 업무`(Tasks 필터 적용) 이동
- 모든 화면에서 `+ 업무 등록` 버튼에 접근 가능해야 한다.

### 상단 요약 카드

| 카드 | 산식 | 클릭 시 |
|---|---|---|
| 전체 업무 | 아카이브 제외 전체 (완료 포함) | Tasks 전체 |
| 진행중 | `IN_PROGRESS` + `OUT_IN_PROGRESS` + `OUT_REVISION` | Tasks(진행중) |
| 검토 | `REVIEW` + `OUT_REVIEW` | Tasks(검토) |
| 완료 | `DONE` | Tasks(완료) |
| 지연 | `is_delayed = true` | Tasks(지연) |
| 이슈 | `status ∈ {OPEN, CHECKING}` 인 이슈 건수 | Issues(미해결) |

> 지연·이슈 카드는 값이 0보다 크면 강조 색으로 표시한다. 0이면 회색.

### 섹션별 규칙

| 섹션 | 정렬 | 표시 상한 | 클릭 시 |
|---|---|---|---|
| 프로젝트별 진행 | `sort_order` → 이름 | 전체 | Tasks(프로젝트 필터) |
| 업무 영역별 진행 | 고정 순서 (사업관리→기타) | 전체 | Tasks(영역 필터) |
| 담당자별 현황 | 담당 업무 수 내림차순 | 상위 10명 + `전체 보기` | Tasks(담당자 필터) |
| 외주 진행 현황 | - | - | Tasks(외주 필터) |

- 진행률 산식은 [03-데이터 모델 §3.5](03-data-model.md#35-진행률-산식) 참조.
- 업무 0건 항목은 진행률을 `-`로 표기한다.

### 기간 기준

Overview는 **현재 시점 스냅샷**이다. 기간 필터를 두지 않는다.
기간별 변화는 Weekly에서 본다.

## 6.3 담당자별 현황 (상세)

```
김OO
────────────────
담당 업무  8
진행중     4
검토       1
완료       3
지연       0
████████░░ 72%
```

- 담당자를 선택하면 Tasks 화면으로 이동하며 `owner` 필터가 적용된다.
- 협업자로만 참여한 업무는 **담당 업무 수에 포함하지 않는다.** (책임 주체 기준 집계)
  상세 화면에서 `협업 참여 N건`을 별도 줄로 표시한다.

## 6.7 공통 표시 규칙

| 요소 | 규칙 |
|---|---|
| 날짜 | 당해년도는 `9/8`, 연도가 다르면 `2026. 1. 5` |
| D-Day | `D-2`, `D-DAY`, 지연은 `-3일` (빨간색) |
| 담당자 | 프로필 이미지(20px) + 이름. 비활성은 이름 뒤 `(비활성)` |
| 상태 배지 | 대기 회색 / 진행중 파랑 / 검토 보라 / 완료 초록 |
| 외주 상태 배지 | 동일 색계열 + 외주 아이콘 |
| 지연 | ⚠ + 빨강 |
| 이슈 | 🔥 |
| 진행률 바 | 10칸 블록. 값이 없으면 `-` |

## 6.8 반응형

| 뷰포트 | 대응 |
|---|---|
| 데스크톱 (≥1024px) | 기본 레이아웃 |
| 태블릿 (768~1023px) | Overview 2단 → 1단, 목록 컬럼 축약(영역·우선순위 숨김) |
| 모바일 (<768px) | 목록을 카드형으로 전환. 업무명·담당·마감·상태만 표시 |

> 모바일은 **조회와 상태 변경**까지만 지원한다. 업무 등록은 데스크톱 우선.

## 6.9 빈 상태 · 오류

| 화면 | 빈 상태 문구 | 액션 |
|---|---|---|
| Overview | "아직 등록된 업무가 없습니다" | `+ 업무 등록` |
| Tasks | "첫 업무를 등록해 보세요" | `+ 업무 등록` |
| Tasks (필터) | "조건에 맞는 업무가 없습니다" | `필터 초기화` |
| Issues | "등록된 이슈가 없습니다" | `+ 이슈 등록` |
| Weekly | "리포트를 생성할 데이터가 부족합니다" | - |
| 공통 오류 | "불러오지 못했습니다" | `다시 시도` |
