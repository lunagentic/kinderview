# 08. Weekly Report 스펙

## 8.1 원칙

업무 및 이슈 데이터를 기준으로 **자동 생성**한다.
리포트를 위해 사람이 따로 입력하는 필드는 **하나도 없다.** (원칙 8)

- 생성 주기: 매주 **금요일 17:00**
- 집계 기간: 해당 주 **월요일 00:00 ~ 일요일 23:59** (생성 시점까지의 실적 + 예정)
- 생성 시점 스냅샷을 `WEEKLY_REPORT.snapshot`에 저장한다. 이후 데이터가 바뀌어도 지난 리포트는 불변.
- 수동 재생성: Weekly 화면에서 `다시 생성` 가능. 기존 리포트를 덮어쓰지 않고 새 버전으로 저장.

## 8.2 구성 항목

### ① 전체 업무 현황

| 항목 | 산식 |
|---|---|
| 이번 주 완료 | `completed_at` 이 기간 내 |
| 진행중 | 기간 종료 시점 `IN_PROGRESS` + `OUT_IN_PROGRESS` + `OUT_REVISION` |
| 검토 | `REVIEW` + `OUT_REVIEW` |
| 지연 | `is_delayed = true` |
| 신규 등록 | `created_at` 이 기간 내 |

### ② 프로젝트별 진행

- 프로젝트별 진행률(%)과 **지난주 대비 증감**(`+7%p`)
- 프로젝트별 이번 주 완료 건수, 지연 건수
- 증감은 직전 `WEEKLY_REPORT.snapshot`과 비교한다. 직전 리포트가 없으면 `-`.

### ③ 업무 영역별 진행

서비스기획 / 디자인 / 개발 / 콘텐츠 / 마케팅 / 사업전략 / 운영 / 외주 작업 / 기타
— 영역별 진행률 및 이번 주 완료 건수.

### ④ 주요 완료 업무

- 이번 주 `DONE`으로 전환된 업무 (`TASK_EVENT`의 `STATUS_CHANGED → DONE` 기준)
- 정렬: 우선순위 `높음` → 프로젝트 → 완료일
- 표시 상한 10건. 초과 시 `외 N건`

### ⑤ 진행 및 지연 업무

- **진행중**: 상태가 진행 단계인 업무, 마감일 오름차순
- **지연**: `is_delayed = true`. 지연 일수 내림차순 (가장 오래 밀린 것부터)
- 각 항목에 담당자·마감일·지연 일수 표기

### ⑥ 외주 진행 현황

```
진행 외주   6건
검수        2건
수정        1건
납품 지연   1건
```

| 항목 | 산식 |
|---|---|
| 진행 외주 | `area = OUT` AND `status ∈ {REQUESTED, OUT_IN_PROGRESS}` |
| 검수 | `status = OUT_REVIEW` |
| 수정 | `status = OUT_REVISION` |
| 납품 지연 | `status ≠ DONE` AND `delivery_due_date < 기준일` |

납품 지연 건은 업체명·내부 담당자·지연 일수를 함께 표기한다.

### ⑦ 주요 이슈

- `status ∈ {OPEN, CHECKING}` 인 이슈
- 정렬: 중요도 내림차순 → 해결 목표일
- 이번 주 신규 등록 이슈와 해결된 이슈 건수를 함께 표기

### ⑧ 리드별 현황

| 컬럼 | 내용 |
|---|---|
| 리드 | 이름 |
| 담당 업무 | 전체 담당 건수 |
| 진행 | 진행 단계 건수 |
| 완료 | 이번 주 완료 건수 |
| 지연 | 지연 건수 |

- 담당 업무 0건인 리드는 표에서 제외한다.
- 비활성 구성원이 리드인 영역은 `인수인계 필요`로 별도 표기한다.

### ⑨ 다음 주 주요 업무

- 다음 주(월~일) 내 마감 예정 업무
- 다음 주 시작 예정 업무 (`start_date`가 다음 주)
- 외주 납품 예정 건
- 정렬: 마감일 오름차순 → 우선순위

## 8.3 Slack 공유

- 생성 완료 시 지정 채널에 요약 + 링크를 게시한다.
- 게시 시점: 금요일 17:05 (생성 5분 후, 검토 여유)
- **결정 필요** — `TBD:` 자동 게시 vs. 담당자 확인 후 수동 게시.
  MVP는 **자동 게시**로 시작하고, 생성~게시 사이 5분간 Weekly 화면에서 수정 가능하도록 한다.

### Slack 메시지 형식

```
📊 KinderFlow Weekly Report  (9/1 ~ 9/7)

이번 주 완료 12건 · 진행 21건 · 검토 7건 · 지연 5건

프로젝트
· Kinderverse    72%  (+7%p)
· 콘텐츠 패키지   61%  (+3%p)
· Global Pilot   48%  (-)

⚠ 지연 5건 · 🔥 미해결 이슈 4건 · 외주 납품 지연 1건

[리포트 전체 보기]
```

## 8.4 Weekly 화면

```
Weekly Report                    2026. 9. 1 ~ 9. 7  [◀ 이전] [다음 ▶]
──────────────────────────────────────────────────────────
① 전체 업무 현황
② 프로젝트별 진행
③ 업무 영역별 진행
④ 주요 완료 업무
⑤ 진행 및 지연 업무
⑥ 외주 진행 현황
⑦ 주요 이슈
⑧ 리드별 현황
⑨ 다음 주 주요 업무
──────────────────────────────────────────────────────────
[다시 생성]  [Slack 공유]  [텍스트 복사]
```

- 이전/다음 주 리포트를 넘겨볼 수 있다.
- `텍스트 복사` — 마크다운 형식으로 클립보드 복사 (보고 문서에 붙여넣기 용도)
- 아직 생성되지 않은 주는 `미리보기` 버튼으로 현재 데이터 기준 임시 생성 가능 (저장하지 않음)
