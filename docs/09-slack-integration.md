# 09. Slack 연동 스펙

## 9.1 Slack의 역할

**구성원 정보 + 알림.** KinderFlow가 Slack의 기능을 대체하지 않는다.

| 역할 | 내용 |
|---|---|
| 구성원 정보 | Slack 멤버를 KinderFlow 담당자로 사용 (별도 구성원 DB 없음) |
| 인증 | Sign in with Slack (OAuth) |
| 알림 | 담당 업무·마감·지연·검토·이슈·외주·Weekly Report |

논의와 대화는 Slack에 남는다. KinderFlow는 댓글 기능을 만들지 않는다.

## 9.2 필요 Scope

| Scope | 용도 |
|---|---|
| `users:read` | 멤버 목록 동기화 |
| `users:read.email` | 이메일 매칭 (선택) |
| `chat:write` | 알림 발송 |
| `im:write` | DM 채널 개설 |
| `openid`, `profile`, `email` | Sign in with Slack |

## 9.3 알림 목록

| # | 알림 | 트리거 | 대상 | 시점 |
|---|---|---|---|---|
| 1 | 담당 업무 등록 | 업무 생성 / 담당자 변경 | 담당자 | 즉시 |
| 2 | 협업 업무 등록 | 협업자 추가 | 협업자 | 즉시 |
| 3 | 마감 D-1 | 배치 | 담당자 | 매일 18:00 |
| 4 | 오늘 마감 | 배치 | 담당자 | 매일 09:00 |
| 5 | 일정 지연 | 배치 (`due_date < 오늘` AND 미완료) | 담당자 + 프로젝트 채널 | 매일 09:30 |
| 6 | 검토 요청 | 상태 → `검토` / `검수` | 프로젝트 리드 | 즉시 |
| 7 | 주요 이슈 발생 | 중요도 `높음` 이슈 등록 | 이슈 담당자 + 프로젝트 채널 | 즉시 |
| 8 | 이슈 등록 | 이슈 등록 | 이슈 담당자, 관련 업무 담당자 | 즉시 |
| 9 | 외주 납품 예정 | 배치 (`delivery_due_date` D-2 / D-DAY) | 내부 담당자 | 매일 09:00 |
| 10 | 외주 납품 지연 | 배치 | 내부 담당자 + 프로젝트 채널 | 매일 09:30 |
| 11 | 검수 반려 | 검수 상태 → `반려` | 내부 담당자 | 즉시 |
| 12 | Weekly Report 공유 | 리포트 생성 | 지정 채널 | 금 17:05 |

### 발송 원칙

- **본인이 일으킨 변경은 본인에게 알리지 않는다.** (자기 액션 알림 억제)
- 동일 업무에 대한 같은 종류의 알림은 **하루 1회**로 제한한다. (지연 알림이 매일 쌓이지 않도록)
- 배치 알림은 담당자별로 **묶어서 1건**으로 발송한다. 업무 3건이면 메시지 3개가 아니라 1개.
- 채널 알림은 프로젝트의 `slack_channel_id`, 미설정 시 기본 채널로 보낸다.

## 9.4 메시지 템플릿

### 담당 업무 등록 (DM)

```
KinderFlow
담당 업무가 등록되었습니다.

프로젝트   Kinderverse
업무       관찰·평가 UX 개선
마감       9월 8일

[업무 확인]
```

### 오늘 마감 / D-1 (DM, 묶음)

```
KinderFlow
오늘 마감인 담당 업무 2건이 있습니다.

· 관찰·평가 UX 개선   Kinderverse   진행중
· 운영 정책 정리      Kinderverse   대기

[내 담당 업무 보기]
```

### 일정 지연 (DM, 묶음)

```
KinderFlow
⚠ 마감일이 지난 담당 업무 1건이 있습니다.

· API 개발   Kinderverse   진행중   3일 지연

[업무 확인]
```

### 검토 요청 (DM)

```
KinderFlow
검토 요청이 있습니다.

업무       제안자료 작성
프로젝트   사업
담당자     이OO

[검토하기]
```

### 주요 이슈 발생 (채널)

```
KinderFlow
🔥 중요 이슈가 등록되었습니다.

이슈       외주 디자인 납품 지연
프로젝트   콘텐츠 패키지
관련 업무   활동지 디자인 제작
담당       김OO
영향       콘텐츠 등록 일정 3일 지연 예상

[이슈 확인]
```

### 외주 납품 예정 (DM)

```
KinderFlow
외주 납품 예정일이 다가옵니다. (D-2)

업무       활동지 디자인 제작
외주 업체   OO 디자인
납품 예정   9월 15일
현재 상태   작업중

[업무 확인]
```

## 9.5 알림 설정

| 항목 | MVP 정책 |
|---|---|
| 개인별 on/off | 알림 종류별 on/off 제공 (마감·지연은 끌 수 없음) |
| 방해 금지 시간 | 미지원. 배치는 업무 시간 내(09:00~18:00)에만 발송 |
| 주말 발송 | 배치 알림은 평일만. 주말 마감 건은 금요일에 함께 안내 |
| 채널 알림 | 프로젝트 단위로 채널 지정 |

## 9.6 실패 처리

| 상황 | 처리 |
|---|---|
| 발송 실패 (일시적) | 최대 3회 재시도 (30초 / 2분 / 10분) |
| 토큰 만료·권한 없음 | 재시도하지 않고 관리 로그에 기록, 관리자에게 안내 |
| 비활성 멤버 대상 | 발송하지 않음 |
| 채널 미설정 | 기본 채널로 대체. 기본 채널도 없으면 발송 생략 |

알림 발송 실패가 업무 저장을 실패시키지 않는다. **알림은 비동기로 처리한다.**
