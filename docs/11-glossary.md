# 11. 용어 사전

문서·UI·코드에서 표기를 통일하기 위한 기준이다.

## 11.1 핵심 용어

| 용어 | 영문/코드 | 정의 |
|---|---|---|
| 프로젝트 | Project | 업무를 묶는 상위 단위 |
| 업무 | Task | 기본 관리 단위 |
| 업무 영역 | Area | 업무의 성격 분류 (7개 고정값) |
| 영역 리드 | Area Lead | 업무 영역의 책임자. **업무의 담당자는 이 사람으로 정해진다** |
| 담당자 | Owner | 업무 진행의 주 담당. 사람을 고르지 않고 **영역 리드가 자동으로 맡는다** |
| 협업자 | Collaborator | 함께 참여하거나 확인이 필요한 구성원 |
| 내부 담당자 | Internal Owner | 외주 작업의 담당자. 값은 `owner`와 동일 |
| 외부 작업자 | Vendor Worker | 외주 업체의 실제 작업자. 사용자 계정 아님 |
| 외주 업체 | Vendor | 외주 수행 업체 |
| 이슈 | Issue | 업무 진행을 막는 문제·블로커 |
| 지연 | Delayed | 마감일이 지난 미완료 업무. **상태가 아니라 플래그** |
| 진행률 | Progress | 상태 가중 평균으로 계산되는 % 값 |

## 11.2 표기 규칙

| 지양 | 사용 | 이유 |
|---|---|---|
| 업무 배정 / 할당 | 담당 정의 | 배정이 아니라 정의 (원칙 1) |
| 업무마다 담당자 지정 | 영역 리드 지정 | 사람이 아니라 영역에 리드를 둔다 |
| 미배정 | (사용하지 않음) | 담당자 없는 업무는 존재하지 않는다 |
| 태스크 | 업무 | 한글 표기 통일 |
| 외주 관리 (메뉴) | 외주 작업 (업무 영역) | 별도 메뉴가 아니다 |
| 지연 상태 | 지연 표시 / 지연 플래그 | 상태값이 아니다 |
| 이슈 상태 = 업무 상태 | 각각 분리 | 원칙 6 |

## 11.3 Enum 정리

### 업무 영역 (`area`)

| 코드 | 표기 |
|---|---|
| `PLAN` | 서비스기획 |
| `DESIGN` | 디자인 |
| `DEV` | 개발 |
| `CONTENT` | 콘텐츠 |
| `MKT` | 마케팅 |
| `BIZ` | 사업전략 |
| `OPS` | 운영 |
| `OUT` | 외주 작업 (짧게: 외주) |
| `ETC` | 기타 |

### 업무 상태 (`task.status`)

| 코드 | 표기 | 적용 |
|---|---|---|
| `TODO` | 대기 | 일반 |
| `IN_PROGRESS` | 진행중 | 일반 |
| `REVIEW` | 검토 | 일반 |
| `REQUEST_PLANNED` | 요청 예정 | 외주 |
| `REQUESTED` | 요청 완료 | 외주 |
| `OUT_IN_PROGRESS` | 작업중 | 외주 |
| `OUT_REVIEW` | 검수 | 외주 |
| `OUT_REVISION` | 수정 | 외주 |
| `DONE` | 완료 | 공통 |

### 검수 상태 (`outsourcing.review_status`)

| 코드 | 표기 |
|---|---|
| `NOT_STARTED` | 미검수 |
| `IN_REVIEW` | 검수중 |
| `APPROVED` | 승인 |
| `REJECTED` | 반려 |

### 지급 상태 (`outsourcing.payment_status`)

| 코드 | 표기 |
|---|---|
| `PLANNED` | 지급 예정 |
| `REQUESTED` | 청구 접수 |
| `PAID` | 지급 완료 |

> 인보이싱은 **외주 업체에 지급**하는 방향이다. 고객 청구가 아니다.

### 이슈 상태 (`issue.status`)

| 코드 | 표기 |
|---|---|
| `OPEN` | Open |
| `CHECKING` | 확인중 |
| `RESOLVED` | 해결 |

### 우선순위 / 중요도 (`priority`, `severity`)

| 코드 | 표기 |
|---|---|
| `HIGH` | 높음 |
| `NORMAL` | 보통 |
| `LOW` | 낮음 |

### 프로젝트 상태 (`project.status`)

| 코드 | 표기 |
|---|---|
| `PLANNED` | 예정 |
| `ACTIVE` | 진행중 |
| `ON_HOLD` | 보류 |
| `DONE` | 완료 |

## 11.4 플래그

| 플래그 | 표기 | 저장 여부 |
|---|---|---|
| 지연 | ⚠ | 저장하지 않음 (조회 시 계산) |
| 이슈 있음 | 🔥 | 저장하지 않음 (조회 시 계산) |
| 납품 지연 | ⚠ | 저장하지 않음 (조회 시 계산) |
